# Устройство Olympus-Lite

## Две отдельные папки

Репозиторий продукта содержит программу, документацию и тесты. Личная библиотека создаётся отдельно:

```text
My-Olympus/
  Home.md
  AGENTS.md
  Sources/
    index.md
    src-.../ver-.../
      original.md
      text.md
      manifest.json
  Knowledge/
    index.md
    concept/source-provenance.md
    guide/import-a-topic.md
    project/my-project.md
  Drafts/
    index.md
    draft-.../page.md
    draft-.../proposal.json
  Journal/
    index.md
    imp-....json
    draft-....json
  .olympus-lite/
    vault.json
    generated.json
    lock.sqlite3
    transactions/
```

Папки Knowledge содержат смысловые страницы, а Sources — полные свидетельства. Их не следует считать взаимозаменяемыми. Ссылки и каталоги позволяют агенту заново восстановить контекст после перезапуска. Здесь нет отдельной скрытой памяти фактов, которая была бы необходима для понимания библиотеки.

## Что проверяет программа

Версия источника определяется исходными байтами, доступным текстом и существенными метаданными. Момент повторного захвата не меняет идентичность. Оригинал и текст проверяются по хешам; версия не должна редактироваться вручную. Для исправления сохраните новый вариант с прежним ключом.

Предложение фиксирует тело страницы, основания и исходный hash целевого файла. Принятие перепроверяет эту связь. Квитанция относится к конкретным байтам; ручная правка позднее оставляет прежнее решение в истории и делает его устаревшим для нового текста.

Проверка цитат устанавливает наличие фрагмента в указанном оригинале. Программа не доказывает истинность источника, полноту аргумента и логическое следование вывода из цитаты. Review — человеческое решение о странице, не универсальная отметка «истина».

## Записи и восстановление

Название продукта исправлено на Olympus-Lite. Новые библиотеки используют `.olympus-lite` и product ID `olympus-lite`. Библиотеки первой сборки с `.olympus-light` продолжают читаться и обновляться через прежний каталог без переписывания оригиналов или квитанций. Если присутствуют оба управляющих каталога, команда сообщает о неоднозначности.

Короткая SQLite-транзакция сериализует записи нескольких локальных процессов. Этот служебный файл использует SQLite из стандартного Python и содержит только блокировку; сервер не запускается, знания в нём не хранятся. После завершения процесса блокировка освобождается операционной системой.

Полная версия источника собирается во временном каталоге и публикуется переименованием. Прерванный проход может оставить `.stage-*`; такие каталоги не считаются завершёнными источниками. Не удаляйте их при работающей команде. После проверки законченных версий они являются временными остатками, не единственным местом подтверждённой истории.

Принятие страницы сначала сохраняет полную транзакцию, затем страницу и квитанцию. Если процесс остановился между ними, повтор approve с тем же предложением и hash завершает действие. Изменившаяся вручную страница не перезаписывается продолжением.

Для резервной копии завершите команды и скопируйте всю папку vault, включая скрытую `.olympus-lite`. Восстановление — копия этой папки в новое место, затем lint. Пересборка каталога не восстанавливает утраченные оригиналы: для них нужна резервная копия.

Одна библиотека рассчитана на локальную работу. Облачная синхронизация не является координатором параллельных записей с нескольких компьютеров. Журнал — проверяемая локальная запись, но не криптографическая идентификация человека или защита от владельца с полным доступом к файловой системе.

## Поиск и ограничения

Поиск сопоставляет слова без учёта регистра. Все слова запроса должны встретиться в названии или тексте; морфологический анализ и синонимы не добавляются автоматически. Исторические discussions/decisions по умолчанию исключены. Бинарные оригиналы без извлечённого текста доступны в каталоге, но не в полнотекстовом поиске.

В версии 0.1 нет автоматического чтения всех разговоров агента, фонового самообучения, Hindsight Reflect, автоматического удаления/забывания, извлечения PDF или медиа и поиска по векторной близости. Эти функции не требуются для работы сохранённых Markdown-страниц.

## Разработка и независимость

Lite реализован на требованиях владельца и собственных [спецификациях](../openspec/specs/file-library/spec.md). Кода, шаблонов, навыков и других файлов коммерческого комплекта Wanderloots в поставке нет. Решение о распространении самого продукта и правах на поставляемые пользователю источники остаётся у владельца.

Использован штатный контракт [sqlite3 Python 3.11](https://docs.python.org/3.11/library/sqlite3.html): отдельные соединения, ограниченное ожидание блокировки и явная транзакция. Документация проверена 06.09.2026. Точные фактически выполненные проверки описаны в [исходной версии](../TEMPLATE.json).
