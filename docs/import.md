# Выборочный перенос прежней Markdown-вики

Импорт читает папки прежней вики. Сервер, API и база Hindsight не используются. Исходная папка и новая библиотека должны находиться отдельно друг от друга.

## Посмотреть состав

```bash
python3 olympus.py inventory /path/to/old-wiki --output /path/to/inventory.json
```

Инвентарь содержит пригодные Markdown/TXT и отдельный список пропусков. Скрытые папки, симлинки, файлы инструкций AGENTS/CLAUDE/GEMINI/SKILL и лицензии не переносятся. Другие форматы не входят в этот импортёр; отдельный явно выбранный бинарный источник можно сохранить командой capture.

## Выбрать материалы

```bash
python3 olympus.py plan /path/to/old-wiki --namespace my-old-library --select '02 Sources/Author Name' --select '03 Concepts/Useful topic.md' --exclude '**/draft-*' --role synthesis --output /path/to/selected-plan.json
```

`--select` можно повторять: точный относительный путь, папка или маска. Namespace — выбранное вами стабильное имя старого корпуса; используйте его при последующих переносах. Не меняйте его случайно: оно участвует в идентичности источника.

Без `--role` материалы имеют роль `unclassified`. Если в одном отборе смешаны первичные источники, синтезы и обсуждения, создайте отдельные планы с правильными ролями. Не определяйте достоверность по названию папки: старые «Sources» тоже могут содержать машинные обзоры.

План фиксирует каждый путь, размер, hash, будущие IDs и общий plan ID. В первой версии проверяется до 1000 выбранных файлов, до 32 МиБ каждый и до 256 МиБ суммарно; большой перенос разбивается на несколько планов. Инвентарь ограничен 50 000 файловыми записями и не объявляется полным при превышении.

## Применить выбранный план

```bash
python3 olympus.py --vault /path/to/wiki import /path/to/selected-plan.json
python3 olympus.py --vault /path/to/wiki lint
```

Перед записями проверяется весь выбранный состав. Если файл изменился после плана, нужен новый план. Известные шаблоны секретов отклоняются без вывода значения; это не универсальная гарантия отсутствия любых секретов.

Повтор того же плана не создаёт дубликатов версий. Изменившийся документ можно перенести новым планом с прежним namespace: старая версия сохранится рядом. Выбранные байты не заменяют автоматически более ранние решения.

## Как выглядит результат

Каждый файл становится источником в каталоге Sources. Его прежний текст и язык сохранены полностью. Manifest связывает его с namespace, относительным путём и hash. Поиск может читать доступный текст и показывает роль материала.

Импорт не создаёт автоматически утверждённые Knowledge-страницы. Даже если в старом тексте есть `status: canonical` или `verified: true`, эти строки остаются историческими данными. Обсуждения и прежние решения находятся через явный `--include-history`.

Ссылки внутри оригиналов не переписываются. Не выбранные связанные страницы и внешние URL не загружаются. Для связного нового материала агент готовит предложение с явными ссылками на перенесённые версии; владелец проверяет его отдельно.

Сбой во время публикации может оставить уже законченные версии без итоговой квитанции всего плана. Повтор проверяет их и завершает перенос. Это возобновляемая операция, а не обещание транзакционного отката всех файлов. Старая вики не изменяется.
