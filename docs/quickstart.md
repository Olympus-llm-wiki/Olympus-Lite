# Быстрый старт

## Демонстрация

Из папки программы:

```bash
python3 scripts/demo.py --output /path/to/new-demo-directory
```

Команда создаёт отдельный каталог с синтетической прежней вики, планами и новой библиотекой. Откройте `Library/Home.md`. В Knowledge будут понятие о происхождении материала, инструкция по переносу и страница учебного проекта. Они ссылаются друг на друга и на сохранённые оригиналы.

Демонстрация сама принимает только собственные синтетические страницы от имени `Synthetic demo owner`. Это не решение о ваших материалах и не образец разрешения агенту одобрять собственные реальные выводы.

## Работа с агентом

Откройте папку личной библиотеки в выбранном агенте с доступом к файлам. В ней есть короткий `AGENTS.md`. При первом запуске укажите, где находится папка программы Olympus-Lite. Сам CLI не выбирает провайдера и не получает ключ модели.

Пример задачи агенту:

> Сохрани этот документ как источник в моей библиотеке. Прочитай его, найди связанные материалы и подготовь одну полезную страницу с основаниями. Покажи мне выводы и цитаты перед принятием.

Для ручной работы те же команды доступны в терминале. Здесь и далее `/path/to/wiki` — папка личной библиотеки, а команды выполняются из репозитория программы.

```bash
python3 olympus.py --vault /path/to/wiki capture /path/to/article.md --key article-001 --title "Название статьи" --role primary
python3 olympus.py --vault /path/to/wiki search "нужные слова"
```

Ответ capture содержит `source_id` и `version_id`. Для бинарного оригинала можно передать `--text-file` с полным извлечённым текстом; без него файл сохранится, но поиск по его содержимому работать не будет. Автоматической расшифровки или извлечения PDF в этой версии нет.

## Подготовить страницу

Агент пишет основной текст страницы в отдельный Markdown-файл. Заголовок и раздел оснований добавит программа. Файл evidence JSON содержит список:

```json
[
  {
    "source_id": "src-…",
    "version_id": "ver-…",
    "claim": "Утверждение, которое поддерживается этим фрагментом",
    "quote": "Точная цитата из text.md указанной версии"
  }
]
```

Используйте реальные ID из capture или import. Программа проверит наличие цитаты; содержательную связь цитаты с выводом проверяет человек.

```bash
python3 olympus.py --vault /path/to/wiki propose /path/to/page-body.md --title "Название страницы" --slug my-topic --kind concept --evidence /path/to/evidence.json
python3 olympus.py --vault /path/to/wiki show draft-...
```

Типы страниц: `note`, `concept`, `topic`, `project`, `guide`. Имена slug — английские буквы, цифры и дефисы. Заголовки и текст могут быть на любом языке.

## Принять или переработать

Прочитайте предложенную страницу в Drafts и основания. После вашего решения агент или вы вызываете:

```bash
python3 olympus.py --vault /path/to/wiki approve draft-... --expected-sha256 HASH_FROM_SHOW --reviewer "Имя владельца"
```

Хеш берётся из `core.page_sha256` команды show или `expected_sha256` команды propose. Он подтверждает, какой именно текст применяется. Значение reviewer фиксирует заявленного участника, но не является аутентификацией человека.

Если нужен другой текст, создайте новое предложение командой propose. Ручное изменение уже подготовленного Drafts/page.md делает прежний hash непригодным. Если изменена целевая страница Knowledge, старое предложение не сможет её перезаписать.

Для внутренних ссылок в теле используйте пути от корня библиотеки через `../../`, например `../../Knowledge/concept/source-provenance.md`. Черновики и итоговые страницы лежат на одинаковой глубине, поэтому такая ссылка работает в обоих местах. Короткая ссылка `../concept/...` из итогового guide не будет работать из Drafts. Obsidian также поддерживает собственные wikilinks, но CLI не перестраивает их автоматически.

## Продолжить в другой сессии

Попросите агента прочитать Home и каталоги, затем найти нужную тему. Устойчивые знания находятся в Knowledge; оригиналы — в Sources; ожидающие предложения — в Drafts. Замечание о качестве можно сохранить как текст с ролью assessment. Оно останется оценкой, а не автоматически включённым правилом.

```bash
python3 olympus.py --vault /path/to/wiki search "старое обсуждение" --include-history
python3 olympus.py --vault /path/to/wiki reindex
python3 olympus.py --vault /path/to/wiki lint
```

Если каталог изменён вручную, reindex покажет конфликт и сохранит его текст. Сравните правку с нужным содержимым; только после этого удалите конкретный производный index.md и повторите reindex. Home и страницы знаний не являются автоматически заменяемыми каталогами.
