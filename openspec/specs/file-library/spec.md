# file-library Specification

## Purpose

Хранить личную библиотеку без сервера памяти так, чтобы исходники и знания оставались читаемыми и проверяемыми обычными файловыми инструментами.

## Requirements

### Requirement: Автономная библиотека
Система SHALL создавать vault с главной страницей и каталогами источников, знаний, черновиков и журнала без Hindsight, сети или дополнительных Python-пакетов. Инициализация SHALL NOT заменять существующую чужую папку.

#### Scenario: Работа без сервисов
- **WHEN** пользователь создаёт новый vault без запущенных служб
- **THEN** получаются обычные Markdown-файлы и локальные команды работают

#### Scenario: Библиотека до исправления названия
- **WHEN** пользователь открывает библиотеку первой сборки со старым идентификатором продукта
- **THEN** она остаётся доступной для чтения и записи без переписывания исходников и решений

### Requirement: Версии источников
Система SHALL сохранять полный original, доступный полный текст, происхождение, роль и hashes. Повтор той же версии SHALL быть идемпотентным. Повреждённая существующая версия SHALL NOT считаться успешным повтором.

#### Scenario: Повторный захват
- **WHEN** источник с тем же ключом и содержимым захватывается повторно
- **THEN** возвращается та же версия без дополнительных копий

#### Scenario: Нет текста бинарного источника
- **WHEN** захвачен бинарный файл без отдельного полного текста
- **THEN** original сохраняется, а отсутствие текста отмечается явно
